# AddressBook

## Description

AddressBook is a Python program that implements a simple address book application using the MVC (Model-View-Controller) architecture. It provides a structured approach to managing contact information, with separate components for data (Model), user interface (View), and logic (Controller).

## Instalation

### Prerequisites
- Python 3.11 or later installed on your system.

### Steps to Install
1. Clone this repository:
```shell
git clone https://github.com/Jaroslawx/AddressBook-MVC
```
2. Navigate to the project directory:
```shell
cd <project_directory>
```
3. Install required Python packages using pip:
```shell
pip install curses tkinter prettytable
```
4. Run app:
```shell
python main.py
```

## Components
- Model: Manages contact data and business logic (e.g., adding, editing, deleting contacts).
- View: Provides the user interface using tkinter for GUI and curses for terminal-based interface.
- Controller: Handles user input, interacts with the Model, and updates the View accordingly.
